# AGENTS.md

Hinweise fuer KI-Agents (Copilot Cloud Agent und andere):

1. Vor jeder Aenderung `./build.sh` ausfuehren und den Ausgangszustand pruefen.
2. Kleine, fokussierte Commits; Commit-Messages auf Englisch im Imperativ.
3. Akzeptanzkriterien aus dem Issue als FPCUnit-Tests abbilden, bevor die Logik implementiert wird.
4. Keine Aenderungen an `.github/workflows/` ohne ausdrueckliche Aufforderung im Issue.
